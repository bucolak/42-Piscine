# 42 Piscine

My exercises from the **42 Istanbul Piscine** — the intensive 4-week selection bootcamp of the 42 school, where peers review each other's code and an automated grader (Moulinette) checks every exercise.

| Folder | Topics |
|---|---|
| `Shell00` | Shell basics, file permissions, links, Git |
| `C00` – `C01` | `write`, loops, pointers, arrays |
| `C02` – `C03` | String manipulation and comparison (`strcpy`, `strcmp`, `strcat`, …) |
| `C04` | Number conversions, `atoi`, printing numbers in any base |
| `C05` | Recursion and iteration (factorial, power, Fibonacci, square root, primes) |
| `C06` | Command-line arguments (`argc` / `argv`), sorting arguments |
| `C07` | Dynamic memory with `malloc` (`strdup`, `range`, `ultimate_range`, `strjoin`) |

All C code follows the 42 **Norm** coding standard and compiles with `cc -Wall -Wextra -Werror`.
